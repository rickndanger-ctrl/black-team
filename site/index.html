Black Team Agent

Private AI. Total control.

Black Team Agent is a local-first AI agent harness for Linux and Mac. Run models on your own computer, optionally add a cloud model with your own key, and let agents work on your files and commands under your approval.

What it does

Your own models

Load a compatible GGUF through llama.cpp, or connect to a local OpenAI-compatible server such as Ollama or LM Studio. Keep several models in one list and switch between them.

Chat and Code

Chat for conversations. Code reads, searches and edits files and runs commands in your chosen folder. It measures your model's speed and sizes its work to match.

Every change shown, with Undo

File edits appear as diffs in the conversation and can be undone. Commands that delete, install or reach the network wait for your approval.

Claude Code and Codex

Use Claude Code or Codex under your own subscription from Code. Choose how much they may do on their own: Ask, Edit or Auto, and roll back a task's changes.

The Room

A room per project, with members and roles. Give the team a goal: the lead plans, members work in turn, and the lead writes a report.

Memory that stays local

A small vault of linked notes that only your local models use. It is not used in cloud conversations or in teams with a cloud member.

Work from your phone

Pair a phone over your own Tailscale network and use the same workspace from a browser on iPhone or Android. Your computer does the work.

A terminal command

black-team starts a session in a terminal, or asks one question with black-team -p. It uses the same models, conversations, projects and memory as the app.

Your privacy

With a local model, prompts and inference stay on your computer. These are the rules, in short. The privacy page has more, and the full rules are in docs/PRIVACY.md.

  • Model requests go only to a loopback address on your computer. Black Team never switches silently to a hosted AI service.
  • A cloud model is opt-in: you add it with your own key. Before a private conversation would leave your computer, Black Team stops and asks, and says what would be sent.
  • Your key is kept in a private file readable only by you, is never shown again, and is sent only to the service you entered it for.
  • Agent tools run as your Linux user. The chosen workspace is a working folder, not a sandbox.
  • Your data stays on your computer, but it is not encrypted by Black Team. Your account, disk encryption and backups still matter.
  • Tools that browse the web or use online services make network requests. Phone access uses Tailscale's own account and network.
  • There is no Black Team account, analytics, or hosted chat backend.

Install

Black Team Agent does not bundle models, llama.cpp, Hermes or other harnesses. You connect those yourself, from Settings. Each release also has a .sha256 file to check your download.

Linux (x86-64)

  1. Download black-team-0.1.0-alpha.26-linux-x64.tar.gz and its .sha256 file into one folder. Open the releases page if the links do not work.
  2. Check it: sha256sum -c black-team-0.1.0-alpha.26-linux-x64.tar.gz.sha256
  3. Extract it: tar -xzf black-team-0.1.0-alpha.26-linux-x64.tar.gz
  4. From the extracted folder, run ./install.sh. No administrator access is needed. Open Black Team from your applications menu, or run ~/.local/bin/black-team-desktop.

Updating: quit the app, extract the newer archive and run its ./install.sh. Your data stays in place. black-team-desktop --rollback returns to the previous release. On Ubuntu 24.04 and later the window may need a one-time sandbox step; see the installation notes.

The installer also links the black-team terminal command next to black-team-desktop when that name is free. The Mac app includes it, as shown in the macOS steps.

macOS (Apple Silicon)

  1. Download Black-Team-0.1.0-alpha.26-mac-arm64.zip and its .sha256 file. Open the releases page if the links do not work.
  2. Check it: shasum -a 256 -c Black-Team-0.1.0-alpha.26-mac-arm64.zip.sha256
  3. Unzip it and move Black Team.app to Applications. The app is signed and notarized by Apple.
  4. To use the terminal command, run once: /Applications/Black\ Team.app/Contents/MacOS/black-team install-command

Next: connect a model

On first start, Workspace lists the local model servers and model files it finds on your computer. Choose one, then choose Save and open chat. Ollama and LM Studio are found at their usual local addresses. The model setup guide explains the rest.
